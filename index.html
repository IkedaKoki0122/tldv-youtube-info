tl-dv YouTube Sync

所有者本人が参加したtl;dvの録画を、本人が指定したYouTubeチャンネルへ限定公開で転送する個人用ツールです。GitHub Actionsで定期実行します。一般向けの利用登録は提供していません。

プライバシーポリシー · 利用条件

プライバシーポリシー

本ツールは、録画の転送と転送結果の確認のために、GoogleのYouTubeアップロード権限および読み取り権限を利用します。投稿先チャンネルのID・名称と、転送した動画のID・公開設定・処理状態を取得します。tl;dvからは本人が参加した会議の一覧・名称・識別子・録画を取得します。

録画はGitHub Actionsの一時実行環境を経由し、YouTubeへ限定公開でアップロードします。限定公開の動画はURLを知る人が視聴できます。録画ファイルをGitリポジトリやActions Artifactへ保存しません。

APIキー・OAuth認証情報は非公開リポジトリのGitHub Secretsに保存します。本人認証の補助プログラムはローカルのメモリ上で認証情報を処理し、平文ファイルを作成しません。会議名・識別子、動画ID、転送状態、期限付きアップロードセッションURLは重複防止・再開のため、非公開リポジトリに保存します。

データの受け渡し先は、機能の実行に必要なtl;dv、GitHub、Google／YouTubeです。広告配信、販売、信用評価、AIモデルの学習には使用しません。Google APIから取得した情報の利用と他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

所有者はGitHubの自動実行を停止し、Googleアカウントの連携設定でアクセス許可を取り消せます。YouTube上の動画はYouTube Studioから管理・削除できます。Secretsと転送状態は所有者が削除するまで保存されます。状態の削除前には自動実行を停止してください。Gitの履歴に残る情報の削除には履歴を含めた削除が必要です。各サービス側の保持条件は各サービスのポリシーに従います。

利用条件

本ツールは所有者本人の利用専用です。所有者は、転送する録画について必要な権利・関係者の許可を確認し、tl;dv、GitHub、YouTubeの適用される規約に従って使用します。第三者向けのサービス提供やサポート契約はありません。
